# TargNES
An NES port of both Exidy arcade games Targ and Spectar. Also contains two additional modes: Survival (Universal Chaos) and Maze.

The D-Pad is used to move the Wummel (your car). Moving the D-Pad in the opposite direction of the Wummel doesn't immediately flip 
it 180 degrees like it does in Pac-Man; instead it slows the car down until eventually it flips.

Pressing A fires a missile. You can only have one onscreen at a time.

Pressing B makes the Wummel invincible for one second and uses one super-meter. If an enemy collides with you during this period, it is destroyed.

Pressing the Select button drops a land mine that will destroy an enemy vehicle if they run over it. This uses one super-meter.

Each enemy destroyed is worth 10 points multiplied by whatever level you are on, capped at 90.

A super-enemy will appear if you do not clear the level quickly enough. Each super-enemy destroyed is worth 100 points multiplied by whatever level you are on, capped at 900.

Clearing a level earns you 1000 points multiplied by whatever level you are on, capped at 9000.

There are four game modes:

Targ - the original game

Spectar - the sequel, in which you can also finish a level by picking up 36 dollar sign pickups worth (10 x level) points each

Universal Chaos - survival mode - kill one enemy, another faster one appears 

Maze - escape the maze to move to the next level - shooting an enemy will spawn another faster one in the opposite corner of the maze
